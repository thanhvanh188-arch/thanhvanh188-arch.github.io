# Digital Museum — 数字博物馆生成技能

## 用途说明

本技能将一个普通的图片素材文件夹，转化为一个具有真实博物馆质感的数字博物馆单页网站。典型场景：文物展示、岩画/壁画/书法作品陈列、藏品图集、文化遗产数字展馆。

**触发条件**（满足其一即应触发）：
- 用户要求制作"数字博物馆"、"博物馆网页"、"展陈页面"、"藏品展示页"
- 用户提供了一个图片素材文件夹（通常名为 images），希望以博物馆形式陈列
- 用户提到"展柜效果"、"射灯"、"画框"、"语音讲解员"等博物馆展陈关键词

## 输入要求

1. 工作目录下必须存在 `images/` 文件夹，内含网页要用的图片素材（jpg/png 均可）。
2. 若工作目录没有 images 文件夹，先在常见位置（Downloads、Desktop、压缩包如 `*RockArt.zip` / `*Huashan*.zip` 等）搜索用户提到的素材包并解压到工作目录 `images/`；确实找不到时再询问用户。
3. 用 `ls images/` 获取全部图片文件名，逐一为图片起中文名称（放入 JS 的 COLLECTION 数组），文件名必须与实际文件完全一致。
4. 生成后用脚本校验：COLLECTION 中引用的每个文件都真实存在，缺失数为 0。

## 风格要求（必须遵守）

- **深色背景 + 金色点缀**的博物馆风格：
  - 背景：深褐黑系（如 `#12100c`、`#1c1913`），可用径向渐变加顶部微光
  - 点缀金：主金色 `#c9a45c`、亮金 `#e8c884`、弱金边 `rgba(201,164,92,0.35)`
  - 正文文字：米白 `#ece5d8` / 次级 `#a89d8a`
  - 字体：中文衬线（Noto Serif SC / Songti / SimSun），标题加大字距（letter-spacing）
- 常用装饰元素：菱形符号 ◆ ❖ ◈、金色细线分隔、圆形描边按钮、铜牌质感徽章

## 完整生成步骤

### 第 1 步：基础网页结构
- **顶部**：博物馆名称大标题（金色、发光 text-shadow）+ 副标题 + 「世界文化遗产」等徽章（金色描边胶囊）
- **主体**：主图展示区 + 文物简介文字（简介含数据卡片行：年代 / 数量 / 规模等，数字用亮金大字）
- **底部**：藏品陈列区（缩略图网格），点击缩略图淡入切换主图；缩略图带中文名称，当前选中项高亮并标「◈ 展出中」
- 所有代码写入单个 `index.html`（内联 CSS + JS，无外部依赖），与 `images/` 同级

### 第 2 步：展柜效果（主图区 museum-case 化）
- **射灯**：展柜顶部中央金属灯具（灯口暖光亮点）+ `clip-path` 锥形光束（模糊 + `mix-blend-mode: screen`）+ 椭圆光晕
- **深色画框**：图片外包深棕木纹渐变画框，金色内压线（inset box-shadow），外加大范围落影 + 近影双层投影
- **玻璃反光**：图片表面覆盖两道斜向白色高光渐变（`linear-gradient` 约 112° 和 100°）+ 顶部轻泛白，`pointer-events: none`
- **台座**：画框下方深色台座（顶板 + 渐变柜身 + 金色铜牌刻文物名与年代），落地处加暖光光斑阴影
- 展柜内壁加两侧暗角，层级（z-index）：背景 < 画框/台座 < 光束/按钮 < 金色角饰

### 第 3 步：交互功能
- **全屏放大查看**：点击主图弹出全屏遮罩（半透明黑 + `backdrop-filter: blur`），大图带画框投影与藏品名；点击任意位置或按 ESC 关闭；放大状态下 ←/→ 可切换且与展柜同步
- **AI 色彩还原按钮**：画框与台座之间的金色胶囊按钮。开启后主图与放大图同时应用 `filter: saturate(1.65) contrast(1.08) brightness(1.03)`，播放一道绿金扫描线动画（约 0.9s），按钮圆点变呼吸绿灯、文案变「还原效果已开启」；再次点击关闭
- **前/后切换按钮**：画框左右两侧金色描边圆形按钮（‹ ›），悬停发亮放大；点击切换上/下一张并同步缩略图高亮、编号、灯箱；小屏时按钮缩小贴边避免裁剪
- 键盘：ESC 优先关闭放大层，←/→ 切换藏品

### 第 4 步：中英文语音讲解员
- 用浏览器原生 Web Speech API（`speechSynthesis`），零外部依赖，符合单文件原则
- 在展柜附近加「▶ 语音讲解」按钮 + 中/英语言切换（zh-CN / en-US）
- 为每件藏品准备一段中文讲解词和一段英文讲解词（可按藏品名生成简短模板文案，如"这件藏品名为……，描绘了……"），切换藏品时若讲解开启则自动播报新藏品
- 实现要点：`new SpeechSynthesisUtterance(text)`，设置 `utterance.lang` 与 `utterance.rate≈0.95`；切换语言或藏品前先 `speechSynthesis.cancel()`；页面卸载时同样 cancel；浏览器不支持时隐藏按钮并降级
- 讲解播放中按钮显示「■ 停止讲解」状态

## 输出要求

- 全部代码写入工作目录下的 `index.html`（单文件：内联 `<style>` 与 `<script>`，不引用外部 CSS/JS/字体文件）
- `index.html` 必须与 `images/` 文件夹在同一级目录，图片以相对路径 `images/<文件名>` 引用
- 完成后用 `present_files` 打开 index.html 预览
